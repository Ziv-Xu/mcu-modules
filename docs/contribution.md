# 📜 一、命名规范总则
- 风格选择：统一使用 下划线命名法 (snake_case)。
- 核心原则：模块名前缀 是避免命名冲突和提升可扩展性。所有全局可见的标识符（函数、类型、宏、全局变量）都必须带有模块前缀，例如 button、sensor。
- 禁止事项：
禁止使用双下划线 __ 开头或包含双下划线的标识符
禁止使用下划线 _ 开头后跟大写字母（如 _Bool）
避免使用 int、char 等模糊类型，除非是标准库强制要求，否则一律使用 <stdint.h> 中的 uint8_t、int32_t 等。
