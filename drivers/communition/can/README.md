##存放can通信相关的代码文件，目前由温鑫然负责完善
##首先声明，目前我仍无法找到用CubeMX来生成过滤器的方法，所以我将过滤器的配置与CAN的开启都放在了MyCAN.c文件中，在使用时除了MX自动生成的MX_CAN_Init外，还需要自己添加MyCAN_Init。

目前有两种MyCAN.c文件，一种使用轮询，一种使用中断。都具有详细的注释。可自行观看。
CAN目前主要使用数据帧和遥控帧，数据帧用来传输数据，遥控帧用来请求数据。
数据帧包括标准帧和扩展帧，都在一个函数里，使用时不必区分。

标准帧包括SOF（起始）、ID（设备ID，由软件决定）、RTR、IDE、ro、DLC（决定了要传输的数据个数，理论最大为64，目前最大只支持8）、Data（数据）、CRC（校验位）、ACK、EOF（结束）。

使用时只需知道ID、DLC、Data即可。
DLC=Length
