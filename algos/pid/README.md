关键设计总结
要求	实现方式
数据类型抽象	pid_real_t 可配置为 float / double / 定点；基于 stdint.h。
硬件抽象层	pid_hal_t 结构体包含获取时间戳、设置输出的函数指针；控制器不直接访问硬件。
临界区保护	使用宏 PID_ENTER_CRITICAL() / PID_EXIT_CRITICAL()，用户自行实现。
编译器兼容	无 #pragma、内联汇编，使用 PID_INLINE 可配置宏，兼容 ANSI C。
核心与扩展解耦	pid_core 仅含基本 PID 项；抗饱和、滤波、死区等作为 pid_ext 独立模块，通过组合集成到具体控制器。
统一接口多态	所有变体通过 pid_controller_t 句柄 + 函数指针操作，支持 Init/Compute/Reset/SetParams/GetParams。
位置式 PID	包括抗饱和（反计算）、微分滤波、死区、设定值斜坡、输出率限制、手动/自动无扰切换。
增量式 PID	积分分离、输出变化率限制、累积输出限幅、无扰切换。
串级 PID	外环计算产生内环设定值，内环直接输出，可独立调整内外环参数。
自适应 PID	增益调度查表，根据调度变量自动切换底层控制器参数。
持久化接口	pid_params_t 的序列化/反序列化函数声明。
MISRA C 兼容	无动态内存分配，每个模块功能单一，避免隐式类型转换，不依赖平台特性。
文档	所有公共函数/结构体均包含 Doxygen 风格注释。
以上代码可直接按文件名添加到工程中使用，并根据实际硬件实现 HAL 回调与临界区即可。
